# Product Boundaries

## Free WP-Auto Connector (WordPress.org)

The free plugin is a real WordPress MCP product, not a teaser for the SaaS.

Planned free responsibilities:
- direct MCP server for compatible clients;
- WordPress 6.9+ ability registration;
- permission-aware site/content read tools;
- draft/content editing tools;
- media tools;
- taxonomy tools;
- supported SEO abstraction/adapters;
- local connection setup/diagnostics;
- local permission controls;
- local activity visibility where needed for safe operation.

Publishing/destructive capabilities may be added later as explicit opt-in functionality after the draft path is mature.

## WP-Auto Cloud (optional paid service)

Paid service value must be substantive remote functionality, for example:
- hosted MCP gateway and multi-site routing;
- managed OAuth/client connection UX;
- Skill runtime;
- scheduled automation/workflow execution;
- source/research collection;
- keyword analysis and Site Intelligence;
- Search Console integrations;
- content QA;
- team/agency governance;
- cloud audit retention/analytics;
- AI model orchestration/credits.

## WordPress.org commercial rule

Do not copy paid service logic into the WordPress.org plugin and lock it with a license key. The free connector should not contain locally complete premium features that are disabled only until payment.

If a future local-only premium add-on is needed, it must be distributed separately outside WordPress.org and reviewed independently for licensing, security, and compatibility.
